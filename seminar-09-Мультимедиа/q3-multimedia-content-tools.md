# Конспект: Классификация ПО для работы с мультимедиа

## 1. Редактирование и создание изображений (Графический дизайн)

### 1.1. Профессиональные пакеты для растровой графики
- **Adobe Photoshop** - индустриальный стандарт для ретуши, монтажа, веб-дизайна
- **Affinity Photo** - мощный конкурент с единоразовой оплатой

### 1.2. Программы для векторной графики
- **Adobe Illustrator** - лидер для логотипов, иконок, иллюстраций
- **CorelDRAW** - популярен в полиграфии
- **Figma** - онлайн-стандарт для UI/UX-дизайна

### 1.3. Доступные альтернативы
- **GIMP** - бесплатный редактор с открытым кодом
- **Canva** - онлайн-платформа с шаблонами для непрофессионалов

## 2. Производство и редактирование видео

### 2.1. Профессиональные рабочие станции (NLE)
- **Adobe Premiere Pro** - отраслевой стандарт
- **DaVinci Resolve** - монтаж + цветокоррекция + VFX (есть бесплатная версия)
- **Final Cut Pro** - эксклюзив для macOS

### 2.2. Визуальные эффекты и моушн-дизайн
- **Adobe After Effects** - стандарт для анимированной графики и VFX

### 2.3. Решения для начинающих
- **Adobe Premiere Rush** - упрощенная версия для соцсетей
- **CapCut** - бесплатное приложение с шаблонами
- **iMovie** - простое решение для Apple

## 3. Создание и обработка аудио

### 3.1. Цифровые аудио рабочие станции (DAW)
- **Adobe Audition** - для подкастеров и звукорежиссеров
- **Ableton Live** - для электронной музыки
- **FL Studio, Logic Pro, Cubase** - для аранжировки и сведения

### 3.2. Бесплатные инструменты
- **Audacity** - простой редактор с открытым кодом
- **GarageBand** - бесплатная DAW от Apple

## 4. Создание анимации и 3D-графики

### 4.1. 2D-анимация
- **Adobe Animate** - стандарт для векторной анимации
- **Toon Boom Harmony** - для анимационных фильмов
- **Blender** - включает инструменты 2D-анимации

### 4.2. 3D-графика
- **Blender** - полнофункциональный бесплатный пакет
- **Autodesk Maya & 3ds Max** - индустриальные стандарты для VFX
- **Cinema 4D** - для моушн-дизайна

## Ключевые выводы

- Выбор ПО зависит от: **задач**, **уровня навыков** и **бюджета**
- **Тенденция**: демократизация технологий - сложные инструменты становятся доступнее
- Существуют решения для всех уровней - от новичков до профессионалов
