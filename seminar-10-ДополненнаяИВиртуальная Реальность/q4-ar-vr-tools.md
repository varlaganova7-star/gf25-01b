# Конспект: Ключевые инструменты для создания контента в AR/VR

## 1. Основные технологии
- **AR (дополненная реальность)** – накладывает цифровые объекты на реальный мир через экран смартфона или очков.
- **VR (виртуальная реальность)** – полностью погружает пользователя в смоделированную среду через шлем.

## 2. Unity: универсальная кроссплатформенная среда
- **Принципы:** доступность, гибкость, модульность.
- **Интерфейс:**
  - Scene – визуальное редактирование сцены
  - Game – предварительный просмотр
  - Hierarchy – иерархия объектов
  - Inspector – управление свойствами
- **Разработка:**
  - Визуальная сборка: перетаскивание 3D-моделей, света, камер, интерфейсов.
  - Логика создаётся на C# в виде скриптов-компонентов.
- **Особенности:**
  - Адаптивный рендеринг:
    - Universal Render Pipeline – для мобильных AR/VR
    - High Definition Render Pipeline – для кинематографичной графики
  - Unity Asset Store – библиотека готовых ресурсов
  - Поддержка OpenXR – кроссплатформенная интеграция (ARKit, ARCore, Oculus)

## 3. Unreal Engine: фотореализм и высокая графика
- **Фокус:** визуальное качество, инструменты для художников.
- **Ключевые технологии:**
  - Nanite – импорт детализированных 3D-моделей в реальном времени
  - Lumen – динамическое реалистичное освещение
  - Niagara – система для сложных визуальных эффектов (огонь, дым, частицы)
- **Разработка:**
  - Blueprints – визуальное программирование для логики и механик
  - Нодовый редактор материалов – создание текстур и поверхностей
- **Применение:** высокобюджетные игры, симуляторы, кинематографичные VR-опыты.

## 4. Специализированные программы для создания контента
- **3D-моделирование:** Blender, Maya, ZBrush
- **Текстуры и материалы:** Substance Painter, Adobe Photoshop
- **Анимация:** Maya, Blender
> Контент создаётся в этих программах, затем импортируется в Unity/Unreal.

## 5. Заключение
- AR/VR — это сплав дизайна и программирования.
- Unity и Unreal Engine – центральные хабы, интегрирующие рендеринг, физику, звук, ввод и работу с AR/VR-оборудованием.
- **Ключевой принцип:** комбинация универсальных сред разработки со специализированным ПО для создания убедительного и стабильного цифрового опыта.
