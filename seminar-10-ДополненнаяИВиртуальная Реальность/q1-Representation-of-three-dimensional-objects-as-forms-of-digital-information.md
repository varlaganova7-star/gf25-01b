# Представление трехмерных объектов как формы цифровой информации
## О чем речь ❓
> **Трёхмерный объект в цифровой среде** — это математическое описание структуры, формы и свойств предмета, которое позволяет визуализировать его на экране и взаимодействовать с ним в виртуальном пространстве.
```
В отличие от 2D-изображений, представляющих плоскость пикселей,
3D-модели основаны на координатах x, y, z, задающих положение точек в пространстве. 
На основе этих данных строится геометрическая форма.
```
**3D-объект включает:**

- **геометрию** — форму, контуры, объём
- **текстуры** — изображения, накладываемые на поверхность
- **материалы** — свойства поверхности (блеск, прозрачность, отражение)
- **анимационные данные** — кости, скелеты, ключевые кадры
- **метаданные** — масштаб, авторство, параметры освещения
___
## Основные способы представления трехмерных объектов
### Полигональное представление
>Самый распространённый тип — **полигональная сетка**.

**Объект состоит из:**
- **вершин** — точек в пространстве
- **рёбер** — соединений между точками
- **полигонов** — чаще всего треугольников и четырёхугольников

`Чем больше полигонов — тем выше детализация.`

| Преимущества ✅| Недостатки ❌ |
|--------------|------------|
| Высокая скорость рендеринга | Сложность представления идеально гладких поверхностей |
| Простота обработки | Высокая нагрузка при большом количестве полигонов |
| Широко поддерживается всеми графическими движками | Большой объём данных для высокополигональных моделей |

**Пример:**
```
В играх 2000-х персонажи имели около 2–5 тысяч полигонов.
Сегодня модели для AAA-игр достигают 50–150 тысяч, а иногда и нескольких миллионов.
```

### Поверхностные модели 
> `NURBS` — это математические кривые и поверхности, создаваемые на основе контрольных точек. Они позволяют получать идеально гладкие формы.

**Используются в:**
- промышленном дизайне
- автомобилестроении
- моделировании корпусов кораблей
- создании ювелирных изделий

**Пример:**
```
Большинство деталей автомобилей сначала проектируют в виде NURBS-поверхностей,
а затем превращают в полигональные модели для визуализации.
```

### Воксельное представление
>**Воксели** — это 3D-аналог пикселей, представляющий объект в виде объёма, заполненного элементами одинакового размера.

| Преимущества ✅ | Недостатки ❌ |
|--------------|------------|
| Подходит для моделирования природных объектов (облака, ткани, почва, органы) | Большие объёмы данных |
| Эффективен в медицинской визуализации (КТ, МРТ) | Медленная обработка |
| Простая структура | Фиксированное разрешение (не масштабируется без потери данных) |

**Пример:**
```
Игра Minecraft работает на вокселях — каждый блок — это воксель, который можно изменить.
```
### Параметрические модели
>Объект задаётся математическими параметрами.   

**Например:**
- радиус
- высота
- количество сегментов
- формулы генерации
  
`Такие модели легко изменять — достаточно поменять числовые значения.`   

**Пример:**
```
В CAD-системах архитектор может удлинить колонну, просто меняя её высоту, не перестраивая вручную всю геометрию.
```
### Процедурные модели
>Процедурная генерация создаёт объекты по алгоритму.

**Например:**
- генерация ландшафтов
- создание городов
- моделирование космических объектов
- дизайн растительности
  
**Пример:**
```
В игре No Man’s Sky практически вся вселенная создана процедурно — каждое дерево, 
планета и животное генерируются алгоритмом.
```

## Текстуры, материалы и карты

> Для реалистичности 3D-объектов недостаточно только геометрии — используются дополнительные текстуры и материалы.

### Основные типы текстурных карт:

| Карта | Назначение | Эффект |
|-------|------------|---------|
| **Diffuse map** | Основной цвет и рисунок поверхности | Определяет базовый внешний вид объекта |
| **Normal map** | Имитация неровностей и рельефа | Создаёт иллюзию объёма без изменения геометрии |
| **Specular map** | Управление отражением света | Определяет, какие участки блестят сильнее/слабее |
| **Displacement map** | Реальное смещение поверхности | Физически изменяет геометрию объекта |
| **Ambient occlusion** | Мягкие тени в углублениях | Добавляет реалистичности в затенённых областях |
___
## Форматы хранения 3D-объектов
**Популярные форматы:**
- `OBJ` — универсальный, простой текстовый формат, используется в играх, моделировании
- `FBX` — поддерживает анимацию, материалы, используется в кино, анимации, Unity, Unreal Engine
- `STL` — содержит только геометрию, используется в 3D-печати
- `GLTF`/`GLB` — оптимизирован для веба
- `STEP` — параметрические данные, используется в инженерии

**Пример:**
```
Для 3D-печати почти всегда используют формат STL, потому что он прост и передаёт 
только геометрию, необходимую для печати.
```

## Области применения трехмерных объектов
### Промышленность и инженерия
**3D-модели позволяют конструировать:**
- двигатели
- корпуса машин
- детали механизмов 
  
`Перед выпуском изделия создают цифровой двойник и тестируют его в виртуальной среде.`
### Архитектура
**Архитекторы проектируют здания, включая:**
- конструкции
- систему коммуникаций
- интерьер

`Это ускоряет расчёты и помогает визуализировать проект заказчику.`
### Медицина
**3D-модели используются для:**
- подготовки к операциям
- моделирования органов
- создания протезов
  
`КТ и МРТ дают воксельные данные, которые преобразуются в 3D-модели.`
### Развлечения и медиа
**На трёхмерных моделях также основаны:**
- фильмы
- VR-приложения
- игры

`В фильмах Marvel актёры снимаются перед зелёным экраном, а все окружение создаётся 3D-художниками.`
