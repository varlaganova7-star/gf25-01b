# Популярные форматы графических файлов и способы сжатия изображений

## 1. Растровые форматы
>Изображение выводится как матрица из пикселей, что позволяет отразить на мониторе практически что угодно. Так же, на каждый пиксель отводится некоторое равное количество битов – так называемая, глубина кодирования (она же глубина цвета). 

### Характеристики:
1. **Разрешение изображений**: произведение числа пикселей в ширину изображения, на число пикселей в длину изображения (например, 1920×1080)
2. **Глубина кодирования**: число 2 в степени равной глубине кодирования равно количеству цветов, которые возможно закодировать(например, 24 бита = 16,7 млн цветов).
3. **Сжатие**: размер файла = разрешение × глубина кодирования. Сжатие может проходить с потерями и без потерь – соответственно, через удаление избыточной информации об изображении, и через удаление малозаметных мелких деталей.

### Популярные форматы:
- **BMP** (Bitmap) — Растровый формат без сжатия или с простым RLE. Поддерживает несжатые данные, RLE, палитра (до 256 цветов). Эффективен для хранения исходных растровых данных, скриншотов. Неэффективен для веба.


- **JPEG** (Joint Photographic Experts Group) — Растровый формат с потерей качества на основе DCT. Поддерживает  сжатие с потерями, YCbCr, дискретизация цветности..Эффективен для фотографий и реалистичных изображений. Плох для текста и графики.


- **GIF** (Graphic Interchange Format) — Растровый формат с LZW-сжатием и палитрой. поддерживает анимации, прозрачность, 256 цветов. Эффективен для простой графики, логотипов, анимаций. Не для фото.
- **PNG** (Portable Network Graphics)— Растровый формат с Deflate-сжатием без потерь. Поддерживает полноцветные изображения, альфа-канал, палитра. Эффективен для веб-графики, изображений с прозрачностью, когда важно качество.

### ✅ Достоинства форматов:
- Реалистичное отображение деталей.
- Простота редактирования.
- Быстрая обработка.

### ❌ Недостатки форматов:
- Потери качества при масштабировании.
- Большой размер файлов.

## 2. Векторные форматы
>Изображение строится из математических описаний объектов (линий, кривых и т.д.). Размер файла зависит уже не от цветов и разрешения, а от количества объектов и сложности кривых .

### Популярные форматы:
- **SVG** (Scalable Vector Graphics)—  Векторный формат на основе XML. Поддерживает фигуры, текст, анимация, фильтры.Эффективен для логотипов, иконок, интерфейсов. Масштабируется без потерь.
- **AI** (Adobe Ilustrator)— Нативный векторный формат Adobe Illustrator. Поддерживает векторные объекты, слои, шрифты, эффекты. Эффективен для хранения исходных векторных проектов. Не для веба.
- **PDF** (Portable Document Format)— Гибридный формат для документов. Поддерживает векторную и растровую графику.
Эффективен для полиграфии и документов со смешанным содержимым. Сохраняет верстку.
### ✅ Достоинства форматов:
- Без потерь качества при масштабировании.
- Маленький размер файлов. Логотипы быстро загружаются на веб-сайтах.
- Плавные контуры.

### ❌ Недостатки форматов:
- Сложность передачи текстур, шумов и градиентов.
- Медленная визуализация сложных объектов.
- Проблемы совместимости редакторов.

## 3. Способы сжатия изображений

### Без потерь:
1. **RLE** (Run-Length Encoding): заменяет повторяющиеся пиксели на символ и количество повторов.  например, представим пиксельную строку из чередующихся красных и синих полос, отметим красные пиксели как «R», а синие – «B». Благодаря RLE, изначальную строку «RRRRRBBBBBRRRRRBBBBBRRRRRBBBBB» можно сократить до вида «5R5B5R5B5R5B» что позволяет существенно сократить объём файла. Эффективен для изображений с большими областями одного цвета (иконки, скриншоты). Неэффективен для сложных градиентов.
>Поддерживает простые растровые изображения (BMP, TIFF), форматы документов (PDF).
2. **LZW** (Lempel-Ziv-Welch): создаёт «словарь» последовательностей пикселей. Эффективен Для изображений с повторяющимися паттернами (графика, логотипы). Плох для фото.
>Поддерживает GIF, TIFF, PDF.
3. **Deflate**: комбинация LZ77 (удаление повторов) и алгоритма Хаффмана (упрощение кодировки).Универсальный, хорош для почти любых данных (изображения, текст, веб).
>Поддерживает PNG, ZIP, GZIP.

### С потерями:
1. **RGB → YCbCr**: сохраняет яркость, упрощает цветовые данные. Эффективен для сжатия с потерями. Позволяет сильнее сжимать Cb/Cr каналы без видимой потери качества.
>Поддерживает JPEG, видеоформаты.
2. **Палитровое сжатие**: сокращает спектр цветов, уменьшая глубину кодирования и общий вес файла. Эффективен для изображений с малым количеством цветов (графика, диаграммы). Не подходит для фото.
>Поддерживает GIF, BMP с палитрой.
